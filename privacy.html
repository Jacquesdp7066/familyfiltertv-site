Privacy policy

Effective date: 14 September 2026

This policy covers the FamilyFilterTV Android app (TV and phone). It's written in plain language because there genuinely isn't much to disclose — this app does not collect personal data about you.

No account, no personal data collected

FamilyFilterTV does not ask you to register, sign in, or create an account. It does not collect your name, email address, location, contacts, or any other personal identifier. There is no user profile stored anywhere outside your own device.

No analytics, no advertising

This version of FamilyFilterTV contains no analytics SDK, no crash-reporting SDK, no advertising SDK, and no third-party tracking of any kind. Nothing about your usage of the app is sent anywhere for measurement or marketing purposes.

Network requests the app makes

FamilyFilterTV talks to exactly three network destinations, all necessary for it to function as Stremio's external player:

DestinationPurposeWhat is sent
Stremio's own local server running on your device (127.0.0.1) Receive the stream Stremio hands off to FamilyFilterTV for playback Local device traffic only — never leaves the device
v3-cinemeta.strem.io (Stremio's public metadata service) Look up a title's canonical name/episode so subtitles can be matched correctly The release name and/or IMDb id of the title being played
opensubtitles-v3.strem.io (Stremio's free OpenSubtitles add-on) Fetch a matching subtitle file when the video has no built-in subtitle track The video's file hash and file size, and/or the IMDb id and episode number, used to find a matching subtitle

All three connections use HTTPS (the local Stremio connection is loopback traffic on the device itself). No video, audio, or subtitle content you watch is ever uploaded anywhere by FamilyFilterTV — subtitle files are only downloaded, to be read locally during playback.

Local caches

Subtitle files that FamilyFilterTV downloads are cached in the app's private storage on your device so the same title doesn't need to be re-fetched every time. This cache never leaves your device and is cleared if you uninstall the app or clear its storage from Android settings.

Diagnostics screen and notification-listener access

Settings → Diagnostics is an optional screen for checking device compatibility (audio muting behaviour, media-session reporting, and so on). To read what another app is currently playing (title, position, playback state) it needs Android's notification-listener permission, which you are asked to grant explicitly in Android's system settings — the app does not have this access until you turn it on yourself, and you can revoke it at any time from Android's notification-access settings. This is used purely to display live diagnostics on screen; FamilyFilterTV never uploads, stores remotely, or shares anything it reads this way. It reads media-session metadata (what's playing, not notification content), and it never reads the text of your notifications.

Children's privacy

FamilyFilterTV does not knowingly collect personal data from anyone, of any age, because it does not collect personal data at all. The app is intended for use by parents/guardians setting up filtering for family viewing; see the target-audience note in our store listing.

Changes to this policy

If this policy changes — for example when accounts or subscriptions are introduced in a future version — the effective date above will be updated and the change described here before it takes effect for that version.
