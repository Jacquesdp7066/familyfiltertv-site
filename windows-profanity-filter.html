Profanity filter for a Windows PC

Family Filter TV for Windows is an early beta. It mutes the whole computer’s sound for a moment when a flagged word is spoken, while the picture keeps playing. It works with whatever you watch on the PC, in a browser or an app. You pick the show and fix the timing on the Family Filter TV phone app. Because it is an early beta, it can miss words.

What the Windows beta does

It links to your household the same way a TV does. Then it mutes the computer’s sound while a flagged word is spoken. The video is not cut or skipped.

It follows what the computer is playing. A computer cannot tell where it is in a film. So the phone listens to find the place.

You choose how strict the filter is: Off, Mild, Family or Strict. It filters speech only. It does not filter violence or nudity.

What you need

  • A Windows 10 or Windows 11 computer. The download is about 100 MB.
  • An Android phone with the Family Filter TV app, on the same account.
  • An active subscription or a free code, like the other devices. A Windows PC counts as one of your household’s devices.
  • Subtitles for the film or episode. The app tells you when it cannot find them.

How to install it

  1. Download the installer from the Windows section of the download page, and run it. It installs for your user only. You can remove it later in Settings › Apps. There is also a portable zip if you prefer not to install.

  2. Expect a warning. Windows will show a blue “Windows protected your PC” warning because the app is not code-signed yet. Choose More info, then Run anyway.

  3. Link the computer. The app shows a short code. On your phone, open Family Filter TV, go to Account › Link a device and type the code within two minutes.

  4. Start following. On the phone, pick the show and set Follow on to your Windows PC. Then press play on the computer.

  5. Let the phone listen. Allow the microphone when it asks. Keep the phone where it can hear the computer’s speakers. If it cannot hear well, tap Type the time and type the time the player shows.

The honest limits

  • It is an early beta for people who want to help test it.
  • It checks the sound only every couple of seconds, so it can miss words.
  • It mutes the whole computer, not one app. It puts the sound back as it was when it stops. If you muted the PC yourself, it leaves it muted.
  • If the computer ever stays muted, press the keyboard’s mute key or choose Exit from its tray icon.
  • It needs the phone app. It does not work on its own.
  • It needs subtitles for the title.

Not working? Quit it from the tray icon next to the clock, or unlink it in the same menu. Then tell us on the support page. More help with timing is in the setup guide.
