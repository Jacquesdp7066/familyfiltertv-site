Download Family Filter TV

Family Filter TV goes on the television you actually watch — your Android TV or TV box — and on the phone you set the filter from. Most of them install it from Google Play. A few TV boxes don't offer Play at all, and those install the same app directly.

Android TV, using the Downloader app

  1. On the TV, install Downloader (by AFTVnews) from the Google Play Store.
  2. Allow it to install unknown apps: on Android 7, Settings › Apps › Security & restrictions › Unknown sources; on Android 8 and later, Settings › Apps › Special app access › Install unknown apps, then enable it for Downloader.
  3. Open Downloader and enter this address: familyfiltertv.com/apk
  4. Choose Install when it finishes downloading.
  5. Open Family Filter TV. If it asks to install unknown apps too, allow it — that's what lets it check for and install its own updates later from its Settings screen.

Phone

  1. Open this page on the phone and tap Download APK above.
  2. When Android or your browser asks about installing unknown apps, allow it for this one install.
  3. Open the downloaded file to install.

Windows computer (early beta)

Watching on a PC? Family Filter TV for Windows links to your household the same way the TV does and mutes the computer's sound while a flagged word is spoken. It works with whatever you are watching on the PC, in a browser or an app. You still pick the show and fix the timing on the Family Filter TV phone app. See profanity filter for a Windows PC for what it needs and its limits.

Family Filter TV for Windows — early beta

Download the Windows installer

Windows 10 or 11, about 100 MB. Prefer not to install? Download the portable zip instead and run FamilyFilterTV.exe from the unzipped folder. Checksums are listed in the release notes.

  1. Download the installer and run it. It installs for your user only, adds a Start menu entry, and can be removed from Settings › Apps.
  2. Windows will show a blue “Windows protected your PC” warning because the app is not code-signed yet: choose More info, then Run anyway.
  3. The app shows a short code. On your phone, open Family Filter TV, go to Account › Link a device and type the code within two minutes.
  4. On the phone, pick the show, set Follow on to your Windows PC, and press play on the computer.
  5. The phone finds the place in the film by listening, so allow the microphone when it asks and keep the phone where it can hear the computer's speakers. If it cannot hear well, tap Type the time and type the time the player shows. More help is in the setup guide.
  • It mutes the whole computer, not one app, and puts the sound back as it was when it stops. If you muted the PC yourself it leaves it muted.
  • This is an early beta for people who want to help test it. It checks the sound only every couple of seconds, so it can miss words, and if the computer ever stays muted, press the keyboard's mute key or choose Exit from its tray icon.
  • It needs the Family Filter TV phone app on the same account, and an active subscription or free code like the other devices; a Windows PC counts as one of your household's devices.
  • Not working? Quit it from the tray icon next to the clock, or unlink it in the same menu, and tell us at the address below.

Good to know

  • Family Filter TV works with Stremio, and follows along while you watch Netflix and other apps on an Android TV or Google TV. For that you need it on the TV and on an Android phone. English titles only for now, and it does not work with the built-in apps of Samsung, LG and other non-Android TVs. Family Filter TV is not affiliated with Netflix.
  • You can't switch between the Play version and the direct version by updating over the top of one another — they're signed differently. Uninstall one before installing the other.
  • The direct build checks for updates itself — open Family Filter TV, go to Settings, and use Check for updates any time, or wait for it to check automatically.
  • To verify a downloaded APK yourself, compute its SHA-256 (for example shasum -a 256 FamilyFilterTV-direct.apk or an equivalent on-device tool) and compare it to the value shown above.
