Android TV, using the Downloader app

  1. On the TV, install Downloader (by AFTVnews) from the Google Play Store.
  2. Allow it to install unknown apps: on Android 7, Settings › Apps › Security & restrictions › Unknown sources; on Android 8 and later, Settings › Apps › Special app access › Install unknown apps, then enable it for Downloader.
  3. Open Downloader and enter this address: familyfiltertv.com/apk
  4. Choose Install when it finishes downloading.
  5. Open Family Filter TV. If it asks to install unknown apps too, allow it — that's what lets it check for and install its own updates later from its Settings screen.

Phone

  1. Open this page on the phone and tap Download APK above.
  2. When Android or your browser asks about installing unknown apps, allow it for this one install.
  3. Open the downloaded file to install.

Good to know

  • You can't switch between the Play version and the direct version by updating over the top of one another — they're signed differently. Uninstall one before installing the other.
  • The direct build checks for updates itself — open Family Filter TV, go to Settings, and use Check for updates any time, or wait for it to check automatically.
  • To verify a downloaded APK yourself, compute its SHA-256 (for example shasum -a 256 FamilyFilterTV-direct.apk or an equivalent on-device tool) and compare it to the value shown above.
