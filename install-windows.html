Install Family Filter TV on Windows

Family Filter TV for Windows is an early beta. It follows what the computer is playing, in a browser or an app, and mutes the whole computer's sound while a flagged word is spoken. You still use the Family Filter TV phone app to pick the show and keep the timing right.

Needs Windows 10 or 11 and about 100 MB. A computer cannot tell where it is in a film, so the phone listens to the show to find the place. See what it needs and its limits.

Install

  1. Download

    Download the Windows installer. Prefer not to install? Download the portable zip instead and run FamilyFilterTV.exe from the unzipped folder.

  2. Run it

    The installer sets it up for your user only, adds a Start menu entry, and can be removed from Settings › Apps.

  3. Get past the Windows warning

    Windows shows a blue “Windows protected your PC” message because the app is not code-signed yet. Choose More info, then Run anyway.

Link it to your phone

  1. Install Family Filter TV on your Android phone: phone install guide.

  2. The Windows app shows a short code. On the phone, open Family Filter TV, go to Account › Link a device and type the code within two minutes.

  3. On the phone, pick the show and set Follow on to your Windows PC. Press play on the computer.

  4. Allow the microphone when the phone asks, and keep the phone where it can hear the computer's speakers. If it cannot hear well, turn the volume up or use speakers instead of headphones.

Questions

Why does Windows warn me when I run the installer?

The Windows app is an early beta and is not code-signed yet, so Windows shows a blue protected-your-PC warning. Choose More info, then Run anyway.

Does the phone have to listen?

Yes, on a computer. A computer cannot tell where it is in a film, so the phone listens to the show to find the place. Allow the microphone and keep the phone near the computer's speakers.

Does it mute only the video I am watching?

It mutes the whole computer's sound for the moment a flagged word is spoken, then the sound comes back.
